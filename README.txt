高中物理可视化演示工具 - 使用说明

打开方式：
1. 解压整个文件夹。
2. 双击 index.html。
3. 使用左侧列表切换物理主题，右侧拖动参数滑块观察变化。
4. 可按空格键暂停或继续动画，也可以点击右上角的播放/暂停按钮。

发给别人时请注意：
不要只发送你浏览器地址栏里的 file:///C:/... 链接。这个链接指向你自己电脑里的文件，其他人的电脑上没有同一路径和同一份文件，所以打不开。

推荐分享方式：
1. 发送完整压缩包：把 index.html、styles.css、app.js 一起发给老师。老师解压后双击 index.html 即可使用。
2. 做成在线网址：把这三个文件上传到 GitHub Pages、Netlify、学校服务器或其他静态网页托管平台，就会得到一个 https://... 开头的网址，老师直接打开网址即可。

文件说明：
- index.html：网页入口
- styles.css：页面样式
- app.js：物理演示和交互逻辑

请保持三个文件在同一个文件夹中。
